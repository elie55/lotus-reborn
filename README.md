# Lotus Reborn — Battle Prototype

A playable xianxia card battle prototype, playable at https://elie55.github.io/lotus-reborn/.

## Update 2

- Green ally aiming arrow for single-ally support, heal, and shield skills.
- "Acted" label removed (greyed out only).
- Enemies no longer show targets and choose smartly when acting.
- Long-press tooltips and a big skill panel on touch devices.
- Performance optimizations.

## Update 3

Qi-gain orb animations (start of turn and effects) and Lin passive text fix.

## Update 4

Touch-first layout (bigger simplified cards, skill tray, tap-to-target), living animated cards, current-HP bars, green/red buff/debuff rings with hold tooltips, Qi Surge +5% damage per link.
